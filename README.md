## 先说结论：看“中断”，不看“消息数”

官方给 Pro 的定义是每个会话至少 5 倍于免费版的用量。但“5 倍”是个相对数，要不要掏钱，得先看你现在被卡得有多惨。

判断方法很朴素：统计中断，不统计消息。

- 任务收尾时碰到限额，等 5 小时就行，没有损失——这是一次正常的免费版使用。
- 任务做到一半被掐断，整个下午的进度跟着作废——一周出现 **2 次**，浪费的时间成本就已经超过 20 美元的月费了。

所以：

- 每个工作日都拿 Claude 处理一堆小任务，下午经常见顶 → 买；
- 一次对话挂一整天，还一直拖着同一批文档 → 买，长对话烧额度特别快，后面细说；
- 一周只在周日集中用两小时，任务还顺利做完了 → 别买，免费版够用；
- 想用 API 跑自动化脚本 → 别买订阅，直接按 token 付 API。

还有两种人可以跳过整个决策：公司已经发了 Team 或 Enterprise 席位的，别重复买单；注册后只问过几个问题的，先回免费版用满再说——免费版并不是残血试用，联网搜索、跨对话记忆、代码执行、extended thinking 都有。

## 20 美元的 Pro，具体多给了什么

1. **至少 5 倍用量。** 官方帮助中心的口径，这是订阅的基本盘。
2. **the coding agent。** 终端里的编码代理从 Pro 开始提供，不用单独买。但有个容易踩的坑：它和网页聊天**共享同一个限额池**，终端会话会把文件内容和命令输出读回对话，烧额度比聊天猛得多。想知道剩多少，在编码工具里跑 `/status`，或者看网页端的 Settings > Usage。
3. **无限 Projects 和 Research。** 参考文档放进项目里会被缓存，省掉每天重复上传的活儿，也只有新增内容才计入限额。
4. **更多模型和更大上下文。** 付费套餐标准上下文窗口是 200K token，Opus 5 和 Sonnet 5 可以开到 1M。1 个 token 约等于四分之三个英文单词，1M 窗口意味着长文档能在同一个对话里一直读下去。顺带一提，Pro 上用编码 agent 跑 Opus 想要 1M 窗口，需要先启用用量额度。
5. **高峰期优先访问和新功能抢先。** 定价页还把 Claude Cowork、Claude Design、Microsoft 365 和 Outlook 集成列进了 Pro 的权益。

一个容易忽略的点：Pro 不包含 API。要写代码调 Claude，得在 Console 另外开通、按 token 单独扣费，订阅和 API 是两个独立的钱包。

## 额度是怎么烧完的：两道闸门加四个大户

Pro 的限额是两道闸同时生效。第一道是会话限制，每 5 小时重置一次，上午用爆了下午可能就恢复；第二道是每周限制，覆盖所有模型，在你账户固定的每周时间重置——哪天订阅、哪天开始用都不影响这个时间点。两道闸的下一次重置时间都在 Settings > Usage 里能看到。

真正决定消耗速度的是这几件事：

- **长对话。** 模型记不住上一轮，每发一条消息都要把整个对话重发一遍，聊到第 40 轮的单条成本可能是第 1 轮的好几倍。换主题就开新对话，是省额度性价比最高的一条。
- **附件。** 大文档会在该对话的每一轮里被重新读取，一份长 PDF 吃掉的额度可能超过 100 个短问题。只传精简后的版本。
- **工具调用。** 联网搜索、Research、MCP 连接器抓回来的所有内容都会塞进对话。
- **高 effort 的 extended thinking 和反复重新生成的 Artifacts。** 日常任务把思考档位调低。

另外两条习惯：相关问题合并成一条消息发，减少来回；日常杂事用小模型，大模型留给硬骨头。新建聊天、退出登录、换浏览器都动不了计数器，这两个计时器只按时间走。

## Pro、Max 还是 API

Max 是同一个产品，只是额度放大：5x 起价每月 100 美元，20x 每月 200 美元，外加更高输出上限和新功能优先体验。升级信号很具体——你已经改掉了拖长对话、传大文件的毛病，大多数工作周还是用完 Pro 的每周额度；或者每月用量额度上的实际支出已经不小，把这笔钱加到 20 美元上和 100 美元比一比。还没碰到 Pro 上限就买 Max，等于买一份自己用不上的额度。

API 是另一条路，按 token 计费、没有月费。Fable 5 输入 10 美元/百万 token、输出 50 美元/百万；便宜的档位如 Haiku 4.5 是每百万输入 1 美元、输出 5 美元。规律很清楚：人手动输入的场景，订阅通常更便宜、账单可预测；程序自动调用的场景，订阅根本不是正确的购买单位——每周跑几次的脚本每月可能只花几美分，而全天循环运行、卡在重试循环里的 agent，一个下午就能烧掉超过 20 美元。

## 常见问题

### Pro 一个月到底能发多少条消息？

没有标准答案。官方不公布条数，因为计量单位是 token 而不是消息，50 个短问题和 5 次长代码审查的负载完全不同。想看自己的消耗，去 Settings > Usage，比任何公开估算都准。

### 被限额了有什么补救办法？

等重置、启用用量额度（超出部分按标准 API 费率单独出账）、或者升级 Max。如果开了用量额度，建议第 1 天就设好每月消费上限——重试循环里的 agent 是账单事故的常见来源。

### 能和朋友拼一个 Pro 账号吗？

共享登录违反消费者条款，而且两个人挤同一个限额池，额度只会更快见底。真要两人用，要么各买一份 Pro，要么看 Team。

### 买 Pro 会送 API 额度吗？

不会。API 是独立产品、独立余额，订阅费覆盖的是 Claude 应用和 the coding agent，两边的钱互不相通。

Claude 会员值不值得买，说到底是一道算术题：任务中途被打断的次数乘以每次浪费的时间，和每月 20 美元比大小。跑完那一周测试，答案自然就有了。真到了要订阅那一步，套餐表格和付款方案都在上面。
